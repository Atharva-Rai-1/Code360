## Problem Statement

<h4 id="you-are-given-an-array-arr-of-size-n-your-task-is-to-find-out-the-sum-of-maximum-and-minimum-elements-in-the-array">You are given an array “ARR” of size N. Your task is to find out the sum of maximum and minimum elements in the array.</h4>

<h5 id="follow-up">Follow Up:</h5>

<pre><code>Can you do the above task in a minimum number of comparisons?
</code></pre>

<h5 id="input-format">Input format:</h5>

<pre><code>The first line of input contains a single integer T, representing the number of test cases.
Then the T test cases follow. 

The first line of each test case contains a single integer N representing the size of the array &#39;ARR&#39;.

The second line of each test case contains N space separated integers representing the elements of the array “arr”.
</code></pre>

<h5 id="output-format">Output format:</h5>

<pre><code>For each test case, print the sum of the maximum and minimum element of the array &#39;ARR&#39;.
</code></pre>

<h5 id="note">Note:</h5>

<pre><code>You do not need to print anything. It has already been taken care of. Just implement the given function.
</code></pre>

<h5 id="constraints">Constraints:</h5>

<pre><code>1 &lt;= T &lt;= 10
1 &lt;= N &lt;= 10^5 
-10^9 &lt;= ARR[i] &lt;= 10^9

Time limit: 1 second
</code></pre>


<h5 id="sample-input-1">Sample Input 1:</h5>

<pre><code>2
7
1 2 4 5 6 6 6 
6
-1 -4 5 8 9 3
</code></pre>

<h5 id="sample-output-1">Sample Output 1:</h5>

<pre><code>7
5
</code></pre>

<h5 id="explanation-for-sample-input-1">Explanation For Sample Input 1:</h5>

<pre><code>For the first test case, the maximum element in the array is 6 and the minimum element in the array is 1.

For the second test case, the maximum element in the array is 9 and the minimum element in the array is -4.
</code></pre>

<h5 id="sample-input-2">Sample Input 2:</h5>

<pre><code>2
5
3 3 3 3 3 
1
-1
</code></pre>

<h5 id="sample-output-2">Sample Output 2:</h5>

<pre><code>6
-2
</code></pre>
