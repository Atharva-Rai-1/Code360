## Problem Statement

<h4 id="you-are-given-two-numbers-a-and-b-as-input">You are given two numbers <em><strong>&#39;a&#39;</strong></em> and <em><strong>&#39;b&#39;</strong></em> as input.</h4>

<p><br></p>

<h4 id="you-must-swap-the-values-of-a-and-b">You must swap the values of &#39;a&#39; and &#39;b&#39;.</h4>

<p><br></p>

<h5 id="for-example">For Example:</h5>

<pre><code>Input: 
&#39;a&#39; = 8, &#39;b&#39; = 5

Output:
5 8

Explanation:
Initially, the value of &#39;a&#39; and &#39;b&#39; is 8 and 5, respectively.

After swapping, the value of &#39;a&#39; is 5, and the value of &#39;b&#39; is 8.
</code></pre>

<h5 id="input-format">Input Format:</h5>

<pre><code>The first and only input line contains two integers, &#39;a&#39; and &#39;b&#39;, representing the two numbers. 
</code></pre>

<h5 id="output-format">Output Format:</h5>

<pre><code>The first line of output prints the swapped value of &#39;a&#39; and &#39;b&#39;.
</code></pre>

<h5 id="note">Note:</h5>

<pre><code>You do not need to print anything. It has already been taken care of. Just implement the given function.
</code></pre>


<h5 id="sample-input-1">Sample Input 1:</h5>

<pre><code>1 2 
</code></pre>

<h5 id="sample-output-1">Sample Output 1:</h5>

<pre><code>2 1
</code></pre>

<h5 id="explanation-for-sample-input-1">Explanation For Sample Input 1:</h5>

<pre><code>The output of the above test case is 2 1.
</code></pre>

<h5 id="sample-input-2">Sample Input 2:</h5>

<pre><code>5 6
</code></pre>

<h5 id="sample-output-2">Sample Output 2:</h5>

<pre><code>6 5
</code></pre>

<h5 id="explanation-for-sample-input-2">Explanation For Sample Input 2:</h5>

<pre><code>The output of the above test case is  6 5.
</code></pre>

<h5 id="constraints">Constraints:</h5>

<pre><code>-10^5 &lt;= &#39;a&#39;, &#39;b&#39; &lt;= 10 ^ 5

Time Limit: 1 sec
</code></pre>
