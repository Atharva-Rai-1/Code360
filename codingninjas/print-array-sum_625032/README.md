## Problem Statement

<h4 id="given-an-array-of-length-n-you-need-to-find-and-print-the-sum-of-all-elements-of-the-array">Given an array of length N, you need to find and print the sum of all elements of the array.</h4>

<h5 id="input-format">Input Format :</h5>

<pre><code>Line 1 : An Integer N i.e. size of array
Line 2 : N integers which are elements of the array, separated by spaces
</code></pre>

<h5 id="output-format">Output Format :</h5>

<pre><code>Sum
</code></pre>

<h5 id="constraints">Constraints :</h5>

<pre><code>1 &lt;= N &lt;= 10^6
</code></pre>

<p><b>Note for C++: </b><br>It is advisable to declare an array with a size that can accommodate all the elements, considering that N has a maximum value of 10^5.</p>


<h5 id="sample-input">Sample Input :</h5>

<pre><code>3
9 8 9
</code></pre>

<h5 id="sample-output">Sample Output :</h5>

<pre><code>26
</code></pre>
