## Problem Statement

<h4 id="given-an-array-arr-of-size-n-find-the-largest-element-in-the-array">Given an array <em><strong>‘arr’</strong></em> of size <em><strong>‘n’</strong></em> find the largest element in the array.</h4>

<p><br></p>

<h4 id="example">Example:</h4>

<pre><code>Input: &#39;n&#39; = 5, &#39;arr&#39; = [1, 2, 3, 4, 5]

Output: 5

Explanation: From the array {1, 2, 3, 4, 5}, the largest element is 5.
</code></pre>

<h4 id="input-format">Input Format :</h4>

<pre><code>The first line will contain a single integer &#39;n&#39;, the size of the array ‘arr’ 

The second line will contain ‘n’ integers representing the array elements.
</code></pre>

<h4 id="output-format">Output format :</h4>

<pre><code>Print the maximum of elements.
</code></pre>

<h4 id="note">Note :</h4>

<pre><code>You don&#39;t need to print anything. It has already been taken care of. Just implement the given function.
</code></pre>


<h5 id="sample-input-1">Sample input 1:</h5>

<pre><code>6
4 7 8 6 7 6 
</code></pre>

<h5 id="sample-output-1">Sample output 1:</h5>

<pre><code>8
</code></pre>

<h5 id="explanation-of-sample-input-1">Explanation of sample input 1:</h5>

<pre><code>The answer is 8.
From {4 7 8 6 7 6}, 8 is the largest element.
</code></pre>

<h5 id="sample-input-2">Sample input 2:</h5>

<pre><code>8
5 9 3 4 8 4 3 10 
</code></pre>

<h5 id="sample-output-2">Sample output 2:</h5>

<pre><code>10
</code></pre>

<h5 id="expected-time-complexity">Expected Time Complexity:</h5>

<pre><code>O(n), Where ‘n’ is the size of an input array ‘arr’.
</code></pre>

<h5 id="constraints">Constraints :</h5>

<pre><code>1 &lt;= &#39;n&#39; &lt;= 10^5
1 &lt;= &#39;arr[i]&#39; &lt;= 10^9

Time Limit: 1 sec
</code></pre>
