## Problem Statement

<h4 id="you-have-been-given-an-integer-array-list-arr-of-size-n-that-contains-only-integers-0-and-1-write-a-function-to-sort-this-array-list-think-of-a-solution-which-scans-the-array-list-only-once-and-dont-require-use-of-an-extra-array-list">You have been given an integer array/list(ARR) of size N that contains only integers, 0 and 1. Write a function to sort this array/list. Think of a solution which scans the array/list only once and don&#39;t require use of an extra array/list.</h4>

<h5 id="note">Note:</h5>

<pre><code>You need to change in the given array/list itself. Hence, no need to return or print anything. 
</code></pre>

<h5 id="input-format">Input format :</h5>

<pre><code>The first line contains an Integer &#39;t&#39; which denotes the number of test cases or queries to be run. Then the test cases follow.

First line of each test case or query contains an integer &#39;N&#39; representing the size of the array/list.

Second line contains &#39;N&#39; single space separated integers(all 0s and 1s) representing the elements in the array/list.
</code></pre>

<h5 id="output-format">Output format :</h5>

<pre><code>For each test case, print the sorted array/list elements in a row separated by a single space.

Output for every test case will be printed in a separate line.
</code></pre>

<h5 id="constraints">Constraints :</h5>

<pre><code>1 &lt;= t &lt;= 10^2
0 &lt;= N &lt;= 10^5
Time Limit: 1 sec
</code></pre>


<h5 id="sample-input-1">Sample Input 1:</h5>

<pre><code>1
7
0 1 1 0 1 0 1
</code></pre>

<h5 id="sample-output-1">Sample Output 1:</h5>

<pre><code>0 0 0 1 1 1 1
</code></pre>

8

5
0 1 0 1 0
</code></pre>

<h5 id="sample-output-2">Sample Output 2:</h5>

0 0 0 1 1 
</code></pre>
